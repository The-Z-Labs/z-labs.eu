Adversary Simulations and Threat-Led Penetration Testing

Z-Labs brings to you sophisticated adversary simulation and penetration testing services together with advanced R&D capabilities.

Our mission

Z-Labs, founded at 2018 by Mariusz Ziulek former Security Researcher at Intel Corporation, brings expersie in adversarial attack simulation and threat modeling.

At Z-Labs, we believe that effective defense starts with genuine understanding of offense. Our mission is to advance the state of adversary simulation through open, transparent tooling - giving red teams, blue teams, and researchers alike the ability to study, test, and improve detection and response capabilities against real-world attacker tradecraft.

See Our Team →

Adversary simulation toolkit based on bof-launcher library.

The toolkit is a collection of open-source tools built to give red teams and security researchers a flexible, cross-platform foundation for emulating real-world attacker tradecraft.

At the core of the toolkit is bof-launcher, an API for loading, executing, and in-memory masking Beacon Object Files (BOFs) on both Windows and Linux. It is designed to be embedded directly into custom-built agents and implants written in C, Zig, Go, or Rust — giving operators the stealth and low-footprint benefits of BOF execution without being locked into a single commercial C2 framework.

Complementing bof-launcher is z-beacon, a custom-written stage-1 (pre-C2) solution engineered with a small footprint, stealth, and modularity as core design goals. Together, these two components let operators build lightweight, discreet implants that load and run BOFs directly in memory — a technique valued in red team engagements for avoiding disk artifacts and minimizing detection surface.
